## 4. 关键技术细节（复现必读的坑与解法）

### 4.1 WinRT 本地 OCR 管线（PowerShell 5.1）

```
裁剪+放大(GDI+ HighQualityBicubic) → 存临时 PNG → StorageFile→BitmapDecoder→SoftwareBitmap → OcrEngine.RecognizeAsync → Lines/Words(带 BoundingRect) → 换算回全屏坐标
```

**必须的 WinRT 类型预加载**（否则 PS5.1 找不到类型）：

```powershell
Add-Type -AssemblyName System.Drawing
Add-Type -AssemblyName System.Runtime.WindowsRuntime
$null = [Windows.Media.Ocr.OcrEngine,Windows.Media.Ocr,ContentType=WindowsRuntime]
$null = [Windows.Graphics.Imaging.BitmapDecoder,Windows.Graphics.Imaging,ContentType=WindowsRuntime]
$null = [Windows.Storage.StorageFile,Windows.Storage,ContentType=WindowsRuntime]
$null = [Windows.Storage.Streams.IRandomAccessStream,Windows.Storage.Streams,ContentType=WindowsRuntime]
$null = [Windows.Graphics.Imaging.SoftwareBitmap,Windows.Graphics.Imaging,ContentType=WindowsRuntime]
$null = [Windows.Media.Ocr.OcrResult,Windows.Media.Ocr,ContentType=WindowsRuntime]
```

**Async→同步 Await 助手**（WinRT IAsyncOperation 在 PS5.1 不能直接 await）：

```powershell
$asTaskGeneric = ([System.WindowsRuntimeSystemExtensions].GetMethods() |
    Where-Object { $_.Name -eq 'AsTask' -and $_.GetParameters().Count -eq 1 -and $_.GetParameters()[0].ParameterType.Name -eq 'IAsyncOperation`1' })[0]
function Await($WinRtTask, $ResultType) {
    $asTask = $asTaskGeneric.MakeGenericMethod($ResultType)
    $netTask = $asTask.Invoke($null, @($WinRtTask))
    $netTask.Wait(-1) | Out-Null
    return $netTask.Result
}
# 用法: $result = Await ($engine.RecognizeAsync($soft)) ([Windows.Media.Ocr.OcrResult])
```

**坐标换算**：OCR 在放大图上运行，全屏坐标 = `区域偏移 + BoundingRect / 放大倍数`：

```powershell
$sx = [math]::Round($r[0] + $br.X / $scale)   # $r = @(x1,y1,x2,y2)
$sy = [math]::Round($r[1] + $br.Y / $scale)
```

**精度增强**：2x 常规文字 / 3x 小字 / 4x 低对比按钮带；`$bmp.SetResolution(192,192)`（4x 用 384）+ `HighQualityBicubic`。

### 4.2 WinRT 投影陷阱

- 集合必须先包 `@()` 才能索引：`@($result.Lines)`、`@($line.Words)` —— 直接 `$result.Lines[0]` 会失败
- Write 工具生成 **UTF-8 无 BOM** 的 .ps1，PS5.1 按 GBK 读 → 代码里的中文字面量/路径会乱码。**解法：脚本内不用中文，路径用 `$PSScriptRoot`**
- OCR 结果含中文，console 经 Git Bash 输出会 GBK 乱码。**解法：写 UTF-8 文件再 Read**：
  ```powershell
  [System.IO.File]::WriteAllText((Join-Path $dir 'ocr_result.txt'), $sb.ToString(), (New-Object System.Text.UTF8Encoding($false)))
  ```

### 4.3 灰度/反色 ColorMatrix（解码低对比文字，如白字蓝底按钮）

只能用**命名属性** `Matrix00..Matrix44`（`$cm.Matrix[$i][$j]` 报 NullArray；`$cm.Matrix = ...` 报 PropertyAssignmentException）：

```powershell
function Convert-Bitmap($srcBmp, $invert) {
    $v = if ($invert) { -1.0 } else { 1.0 }
    $cm = New-Object System.Drawing.Imaging.ColorMatrix
    $cm.Matrix00 = 0.299*$v; $cm.Matrix01 = 0.299*$v; $cm.Matrix02 = 0.299*$v
    $cm.Matrix10 = 0.587*$v; $cm.Matrix11 = 0.587*$v; $cm.Matrix12 = 0.587*$v
    $cm.Matrix20 = 0.114*$v; $cm.Matrix21 = 0.114*$v; $cm.Matrix22 = 0.114*$v
    $cm.Matrix33 = 1.0; $cm.Matrix44 = 1.0
    if ($invert) { $cm.Matrix40 = 1.0; $cm.Matrix41 = 1.0; $cm.Matrix42 = 1.0 }  # 反色=亮度行取负+平移行+1
    $out = New-Object System.Drawing.Bitmap($srcBmp.Width, $srcBmp.Height)
    $g = [System.Drawing.Graphics]::FromImage($out)
    $ia = New-Object System.Drawing.Imaging.ImageAttributes
    $ia.SetColorMatrix($cm)
    $rect = New-Object System.Drawing.Rectangle(0, 0, $out.Width, $out.Height)
    $g.DrawImage($srcBmp, $rect, 0, 0, $srcBmp.Width, $srcBmp.Height, [System.Drawing.GraphicsUnit]::Pixel, $ia)
    $g.Dispose(); $ia.Dispose()
    return $out
}
```

### 4.4 DrawImage 重载绑定陷阱

当矩形参数来自 hashtable 属性算术（`$b.x2-$b.x1`）时 PS 把参数当 Object[] → UInt32 转换错误。**解法**：区域用 `[ordered]@{ tag=@(x1,y1,x2,y2) }` 数组模式 + 显式 `[int]` 强转 + Rectangle 先存独立变量：

```powershell
$regions = [ordered]@{ 'band1' = @(0, 0, 1050, 400) }
$dst  = New-Object System.Drawing.Rectangle(0, 0, $w2, $h2)
$srcR = New-Object System.Drawing.Rectangle([int]$r[0], [int]$r[1], $w, $h)
$g.DrawImage($src, $dst, $srcR, [System.Drawing.GraphicsUnit]::Pixel)
```

## 7. 使用方式结论（推断的标准报销流程）

1. **系统自动带出**：单据编号、申请日期、申请人身份（姓名/职位/部门/公司/手机）、流程归属、大写金额、应报销金额（由明细汇总计算）
2. **人工填写**：预算年度、报销方式 → 预算带内选择预算部门/单位/科目/项目（联动显示科目限额/余额，系统据此校验）
3. **加行填报**（点分区标题旁 `+`）：
   - 关联单据（可选，如关联公出单）
   - 报销明细（核心：选择报销项目）
   - 费用说明（类型 + 起止日期 + 次数/天 + 项目说明）
4. **上传发票**：附件区上传，**单文件 ≤10MB** 否则系统无法识别
5. **银行信息**：填写收款人/开户行；该区带独立确认流（发送部门→发送人→确认人确认→确认时间/意见）
6. **提交审批**：进入审批链（审批人/部门/职位），逐条生成审批记录（日期/审批日期/审批评论/审批意见）
7. **预算核销**："是否为最后一次" 标记决定该预算科目是否核销关闭
8. 当前单据状态 **编制中** + 全部表格"共0条" = 纯草稿，尚未提交（另有一个"新建报销单×"空页签）
