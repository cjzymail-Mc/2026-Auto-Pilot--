# 入口与未来扩展说明

本文件说明 Skill 文档框架、已固化 runbook 及未来扩展方式。统一业务入口为 [SKILL.md](SKILL.md)：接收模板单号、原始材料及执行意图，读取真实模板，识别单据类型与业务场景，再按需加载对应 runbook。业务执行须遵守仓库 [AGENTS.md](../../../AGENTS.md)、入口安全边界及当次授权。

## 文档框架

以下路径相对于本 Skill 目录，新增手册沿用这一结构：

| 层次 | 位置与职责 |
|---|---|
| 统一入口 Skill | [SKILL.md](SKILL.md)，负责接单、路由、公共流程及安全边界 |
| 公共参考 | [full-chain.md](references/full-chain.md)、[plan-contract.md](references/plan-contract.md)、[evidence-hash-semantics.md](references/evidence-hash-semantics.md)，说明通用链路、计划契约及证据规则 |
| 类型/场景 runbook | `references/<场景名>.md`，说明该类业务的识别条件、原件理解、金额规则、执行步骤与验收边界 |
| 实现及验收状态 | 仓库 [STATE.md](../../../STATE.md) 及其直接证据入口，记录尚未接通的工程与实际验证结果 |

AGENTS.md 保留长期规则和本文件指针；框架与手册登记在此维护，具体业务步骤写入对应 runbook，当前工程进度及恢复线索留在 STATE.md。

实现代码与诊断/验证工具的归类、旧代码路径映射见 [仓库目录与维护入口](../../../docs/repository-layout.md)。

## 已固化 runbook 与扩展预留

**以下登记的是已固化的限定范围手册成果。**手册固化、代码实现、离线通过、真实填写通过和真实保存通过分别记录，不因手册完成就宣称整单自动化已验收。

| 单据/业务场景 | 手册 | 登记状态 |
|---|---|---|
| 报销单—自驾公出类 | [自驾公出类 runbook](references/self-drive.md) | 手册已固化；执行能力与未完成事项见手册及 STATE |
| 报销单—快递费 | [快递费 runbook](references/express.md) | 普通全额、无关联/物品档案，费用说明非空或有源不适用；历史真实只填不存已回读，新业务与真实保存另验；见[收尾结果](../../../feature02-扩展更多单据类型/快递研发runbook收尾结果.md) |
| 报销单—研发材料费 | [研发材料费 runbook](references/rd-materials.md) | 现有档案行金额，关联/费用说明为空；历史真实选档及只填不存已回读，新业务与真实保存另验；见[收尾结果](../../../feature02-扩展更多单据类型/快递研发runbook收尾结果.md) |
| 后续其他类型单据或业务场景 | 预留 `references/<场景名>.md` | 待建设，尚未登记为已固化手册 |

既有 [travel.md](references/travel.md) 保留为其他已支持差旅的类型参考；快递与研发沿用原文件名和统一入口路由，不另建重复 Skill，不顺带接入办公、福利或其他类型。

## 未来新增或升级手册

1. 在对应 runbook 中补齐适用条件、原件与来源要求、金额规则、正式执行入口及验收要求。
2. 在 SKILL.md 增加按真实模板和业务证据判断的路由，按需补齐规则、执行适配与验证，不以文档路由代替实现。
3. 在本文件更新手册登记，并附与完成层次相符的证据入口；工程进度和待办在 STATE.md 维护。
4. 沿用统一入口及现有安全控制，无需提前创建空手册或另建一套入口。文档维护不自动启动施工或真实 OA 操作。
